# Changelog

## 0.3.2a1 — experimental alpha

First public experimental alpha, curated from the existing implementation. Release preparation does not change the profiler or routing architecture.

- Independent Python/SQLite core and JSON CLI; no runtime dependencies.
- Explicit Gate 0 and trusted deterministic-handler registration.
- Cited research, native reasoning identity and immutable profile plans.
- Local Ollama support for tested GGUF and Ollama-managed MLX deployments.
- Optional host-owned OpenClaw/Codex subscription adapter and administrator-only bridge.
- Built-in baseline/contrast fixtures, descriptive bios and durable observations.
- Bounded grants, interruption handling and no automatic uncertain replay.
- Policy-aware previews; native OpenClaw/Hermes enforcement remains unverified.
- Offline usage/quality accounting and optional KRE context interoperability.
- Curated benchmark evidence, portable examples and guides.
- Adopted Apache-2.0 licensing and attribution to 2026 Brandon Gordon and GCB contributors.
- Clean public snapshot with offline GitHub Actions verification and separate CodeQL checks; actual completed results are recorded in the verification documentation.

Private milestone history is excluded from the public repository. Release tags and artifact bytes remain bound to the verified source through the release provenance and checksum records.
