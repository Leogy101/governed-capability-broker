# Known alpha limitations

- **Profiles are small samples.** Usually one fixture per category; extra reasoning settings cover only coding and structured extraction. A correct supplied-source answer does not demonstrate open-web research, and an orchestration plan does not demonstrate executed orchestration. All GPT fixtures passing did not establish equal overall capability.
- **Routing is advisory.** Native OpenClaw/Hermes pre-inference enforcement remains unproven. Eligibility and research are evaluated from the inventory state; previews do not atomically authorize a later external dispatch. Equal observed scores can resolve by stable configuration ID, which is not superiority evidence.
- **Reasoning is provider-specific.** GCB preserves researched native controls. The tested GPT and Ollama responses did not independently echo effective native reasoning. Requested values are not evidence of internal execution. Output counts may include unseparated reasoning work.
- **Usage and billing are incomplete at some boundaries.** Host-reported token fields are useful, but internal provider requests/retries and actual subscription charges may be unknown. Missing fields remain unknown. Cached tokens can already be included in input totals. A smaller local payload is not proof of fewer billed tokens or lower cost.
- **Cancellation has limits.** GCB persists reservations and protects completed/uncertain attempts from automatic replay. A software timeout or transport cancellation does not itself prove remote execution stopped or charges ceased. Bounded grants are not provider-side spending controls.
- **Discovery is explicit.** Ordinary Ollama onboarding starts with an installed tag. Optional host profiling uses a researched, operator-provided snapshot and scoped bridge. Private campaign scheduling, resource monitoring and account-reserve scripts are not features of the installed CLI.
- **Local resources remain the operator's responsibility.** Requested context limits do not guarantee physical memory use. The tested MLX backend did not treat the context request as a 4K allocation. Cold loading, different runners and quantization confound speed comparisons.
- **Local evidence remains partial.** The 9B pilot missed its planning fixture. Standard Qwen3.6 retains two unknown attempts; Abliterated Qwen3.6 has seven untouched cells. Known completed usage cannot make incomplete historical usage complete.
- **Integration coverage is specific.** The verified host execution path is OpenClaw 2026.11.1/Codex 0.169.0-alpha.11.1. Native tool execution/recovery is unmeasured there. Other providers and runtimes are not universally supported. macOS arm64 profiling is verified; Linux is unverified and Windows profiling currently fails closed.
- **Extensions are trusted code.** Registered deterministic Python handlers run in the application process. A handler allowlist is not an operating-system sandbox. Generated benchmark code is never executed.
- **Model access is not bundled.** GCB does not redistribute weights, subscription access or provider licenses. Account availability, model names, versions and limits can change. Real profiling requires authorization and current metadata.
- **Publication examples are projections.** Public evidence excludes private operational/account records and arbitrary raw output. Curated example bios cannot be imported to grant authority. Reproduce arithmetic offline; obtain separate permission before reproducing live inference.

No generalized model-superiority, guaranteed savings, complete native governance or universal-platform claim is part of this alpha. Negative observations stay visible and do not disqualify a technically accessible model from inventory. See the [measured evidence](BENCHMARKS.md) and [compatibility matrix](COMPATIBILITY.md).
