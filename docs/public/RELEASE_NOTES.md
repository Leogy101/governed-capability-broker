# Governed Capability Broker 0.3.2a1

**Prepared alpha candidate; not published. Release version/tag: `0.3.2a1` / `v0.3.2a1`.**

Apache-2.0 is adopted, with copyright attribution to 2026 Brandon Gordon and GCB contributors. The clean public snapshot strategy is approved. Public repository creation, remote pushes and prerelease publication remain unauthorized until the final release approval.

GCB researches model settings, executes a small integrated profile, preserves descriptive observations and explains policy-aware routing previews. Deterministic Gate 0 handles explicit supported operations without an LLM. The independent Python/SQLite package has no runtime dependencies and no KRE requirement.

This candidate includes the existing local Ollama adapter and optional host-owned OpenClaw/Codex subscription bridge. Tested GPT evidence covers seven models, 40 requested settings and 108 correct small-fixture observations. Local evidence includes failures and partial coverage. See [methodology](BENCHMARKS.md); these results do not establish broad model equivalence or general savings.

Verified support is deliberately narrow: macOS arm64, tested Python versions, selected Ollama deployments, and OpenClaw 2026.11.1/Codex 0.169.0-alpha.11.1. The [compatibility matrix](COMPATIBILITY.md) separates working paths, preview-only governance and unverified platforms. Effective reasoning, provider request accounting and subscription billing can remain unknown. Native Codex tool execution is unmeasured.

Start with the [offline demo](../../README.md#five-minute-offline-quickstart), then the [model onboarding guide](ONBOARDING.md). Do not interpret timeouts as billing guarantees or replay uncertain attempts. No automatic live routing or new service is installed.

The remaining publication gates are exact artifact/provenance review, explicit release authorization, verified private vulnerability reporting and successful GitHub CI for the published commit. GitHub CI is prepared but has not executed. A local annotated tag may be prepared after local verification; it is not a public release. No remote repository, public tag, package upload or GitHub release is claimed here.
